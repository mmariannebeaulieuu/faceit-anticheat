DISTRIBUTION OPTIONS
====================

Option 1: Local (No Downloads)
   Distribute:
   - AntiCheatLauncher.exe
   - anticheat_files/anticheat-client.exe
   - release-config.json (URLs empty)

Option 2: Remote (With Downloads)
   Host on server:
   - anticheat-client.exe
   - AntiCheatKernelDriver.sys (optional)
   
   Distribute:
   - AntiCheatLauncher.exe
   - release-config.json (with URLs)

WORKFLOW
========

Development:
1. Edit C++ code in src/
2. Run: build_all.ps1
3. Run: AntiCheatLauncher.exe

Deployment:
1. Build: build_all.ps1
2. Upload files to server (optional)
3. Update release-config.json
4. Distribute: AntiCheatLauncher.exe + config
